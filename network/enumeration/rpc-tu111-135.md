# RPC - 135

#### Null Sessions

{% code lineNumbers="true" %}
```
rpcclient -U "" <ip> -N
enumdomusers //get users
getdompwinfo //password policy
```
{% endcode %}

#### Authenticated

{% code lineNumbers="true" %}
```
rpcclient -U <username> --password <password> <ip> -W <domain>
enumdomusers //get users
getdompwinfo //password policy
```
{% endcode %}

#### RID Cycling

{% code lineNumbers="true" %}
```
for i in $(seq 500 2000); do echo "queryuser $i" | rpcclient -U "" -N <ip> 2>/dev/null | grep -i "User Name"; done
for i in $(seq 500 2000); do echo "queryuser $i" | rpcclient -U <username> --password <password> <ip> -W <domain> 2>/dev/null | grep -i "User Name"; done
```
{% endcode %}
