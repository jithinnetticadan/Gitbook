# NFS - TU111,2049

### Default Configuration

* `/etc/exports`

### Footprinting

{% code lineNumbers="true" %}
```shellscript
nmap -sV -sC -p111,2049 <ip>
nmap -sV -p111,2049 --script "nfs*" <ip>
```
{% endcode %}

### List NFS Mount

```shellscript
showmount -e <ip>
```

### Mount the Share

{% code lineNumbers="true" fullWidth="false" %}
```shellscript
sudo mount -t nfs <IP>:/ /<mount path> -o nolock,ro
sudo mount -t nfs -o ro <ip>:/<sharename> /<mount path> 
sudo mount -t nfs -o ro,vers=2 <ip>:/<sharename> /<mount path> 
sudo mount -t nfs -o rw <ip>:/sharename <mount-path>
sudo mount -t nfs -o rw,vers=2 <ip>:/<sharename> /<mount path> 
```
{% endcode %}

### Enumeration

* **List Contents with Usernames & Group Names**
  * `ls -l <sharename>`&#x20;
* **List Contents with UIDs & GUIDs**
  * `ls -n <sharename>`&#x20;

{% hint style="info" %}
If we have access to the system via SSH and want to read files from another folder that a specific user can read, we would need to upload a shell to the NFS share that has the `SUID` of that user and then run the shell via the SSH user.
{% endhint %}

### Unmount Share

```shellscript
sudo umount <mount path>
```
