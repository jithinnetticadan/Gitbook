# SMB - T139,445,U137,138

### Default Configuration

* `cat /etc/samba/smb.conf | grep -v "#|;"`&#x20;
* <table data-header-hidden><thead><tr><th width="267.85723876953125">Setting</th><th>Description</th></tr></thead><tbody><tr><td><code>[sharename]</code></td><td>The name of the network share.</td></tr><tr><td><code>workgroup = WORKGROUP/DOMAIN</code></td><td>Workgroup that will appear when clients query.</td></tr><tr><td><code>path = /path/here/</code></td><td>The directory to which user is to be given access.</td></tr><tr><td><code>server string = STRING</code></td><td>The string that will show up when a connection is initiated.</td></tr><tr><td><code>unix password sync = yes</code></td><td>Synchronize the UNIX password with the SMB password?</td></tr><tr><td><code>usershare allow guests = yes</code></td><td>Allow non-authenticated users to access defined share?</td></tr><tr><td><code>map to guest = bad user</code></td><td>What to do when a user login request doesn't match a valid UNIX user?</td></tr><tr><td><code>browseable = yes</code></td><td>Should this share be shown in the list of available shares?</td></tr><tr><td><code>guest ok = yes</code></td><td>Allow connecting to the service without using a password?</td></tr><tr><td><code>read only = yes</code></td><td>Allow users to read files only?</td></tr><tr><td><code>create mask = 0700</code></td><td>What permissions need to be set for newly created files?</td></tr></tbody></table>

### Footprinting

{% code lineNumbers="true" %}
```shellscript
smbclient -U <user> -L '\\TARGET_IP\' (list shares)
smbclient -U 'username%password' -W <domain> '\\<sharename-fullpath>'
## Domain Joined Linux. Use -no-pass is optional
smbclient '\\<sharename-fullpath>' -k -c ls -no-pass
smbmap -H TARGET_IP
smbmap -u <user> -p <password> -d <update> -H <ip> -s <share> -r
nmap -p 445 --script smb-enum-shares TARGET_IP
enum4linux -A TARGET_IP
nxc smb TARGET_IP -u "user" -p "password" --shares
impacket-smbclient domain/username:password@target-ip -dc-ip <ip> (also pass NTLM hash using -H)
```
{% endcode %}

{% hint style="info" %}
Smbclient also allows us to execute local system commands using an exclamation mark at the beginning (`!<cmd>`)
{% endhint %}
