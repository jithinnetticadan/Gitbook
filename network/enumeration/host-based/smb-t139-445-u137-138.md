### Footprinting

{% code lineNumbers="true" %}
```shellscript
## Commands to try if we have a working rpcclient session
>>> srvinfo, enumdomains, querydominfo, netshareenumall, netsharegetinfo <share>, enumdomusers, queryuser <RID>
## Brute Forcing User RIDs / Impacket-Samrdump.py (Null or Authenticated)
for i in $(seq 500 1100);do rpcclient -N -U "" <IP> -c "queryuser 0x$(printf '%x\n' $i)" | grep "User Name\|user_rid\|group_rid" && echo "";done
smbclient -U <user> -L '\\TARGET_IP\' (list shares)
smbclient -U 'username%password' -W <domain> '\\<sharename-fullpath>'
## Domain Joined Linux. Use -no-pass is optional
smbclient '\\<sharename-fullpath>' -k -c ls -no-pass
smbmap -H TARGET_IP
smbmap -u <user> -p <password> -d <update> -H <ip> -s <share> -r
nmap -p 445 --script smb-enum-shares TARGET_IP
enum4linux -A TARGET_IP
nxc smb TARGET_IP -u "user" -p "password" --shares
impacket-smbclient domain/username:password@target-ip -dc-ip <ip> (also pass NTLM hash using -H)
```
