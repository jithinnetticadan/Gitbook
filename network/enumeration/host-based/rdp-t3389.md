# RDP - T3389

{% hint style="info" %}
Connect to RDP servers on Linux using `xfreerdp`, `rdesktop`, or `Remmina`
{% endhint %}

### Footprinting <a href="#footprinting-the-service" id="footprinting-the-service"></a>

{% tabs %}
{% tab title="Nmap" %}
{% code lineNumbers="true" %}
```shellscript
sudo nmap -sV -sC -p3389 --script rdp* <IP>
```
{% endcode %}
{% endtab %}
{% endtabs %}

### **Brute Force**

{% tabs %}
{% tab title="Hydra" %}
{% code lineNumbers="true" %}
```shellscript
hydra -L user.list -P password.list rdp://<IP>
```
{% endcode %}
{% endtab %}

{% tab title="NetExec" %}
{% code lineNumbers="true" %}
```shellscript
nxc rdp <IP> -u user.list -p password.list
```
{% endcode %}
{% endtab %}
{% endtabs %}

### **RDP Security Check**

* `./rdp-sec-check.pl <IP>`

### **Initiate RDP Session**

{% code lineNumbers="true" %}
```shellscript
xfreerdp /u:user /p:"password" /v:<IP>
rdesktop <IP> -d <domain> -u <user> -p <password>
```
{% endcode %}
