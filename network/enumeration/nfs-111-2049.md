# NFS - 111,2049

#### Script Scan

```
nmap -sV -p111,2049 --script "nfs*" <ip>
```

#### List NFS Mount

```
showmount -e <ip>
```

#### Mount the Share

{% code lineNumbers="true" fullWidth="true" %}
```
sudo mount -t nfs -o ro <ip>:/<sharename> /<mount path> 
sudo mount -t nfs -o ro,vers=2 <ip>:/<sharename> /<mount path> 
sudo mount -t nfs -o rw <ip>:/sharename <mount-path>
sudo mount -t nfs -o rw,vers=2 <ip>:/<sharename> /<mount path> 
```
{% endcode %}

#### Unmout Share

```
sudo umount <mount path>
```
