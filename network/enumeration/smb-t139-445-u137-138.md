# SMB - 139,445

#### SMB Shares - Null Session

{% code lineNumbers="true" %}
```
smbclient -L //TARGET_IP -N
smbmap -H TARGET_IP
nmap -p 445 --script smb-enum-shares TARGET_IP
enum4linux -a TARGET_IP
```
{% endcode %}

#### Access SMB Shares

{% code lineNumbers="true" fullWidth="false" %}
```
sudo mount -t cifs -o ro,username=<user>,domain=<update> //<sharename> <mount-path> 
sudo mount -t cifs -o ro,username=<user>,domain=<update>,vers=1.0 //<sharename> <mount-path>  
sudo mount -o remount,ro <mount-path> 
sudo umount <mount-path>
smbclient //<sharename> -N
smbclient //<sharename> -U 'username%password' -W <domain>
impacket-smbclient domain/username:password@target-ip -dc-ip <ip> (also pass NTLM hash using -H)
```
{% endcode %}
