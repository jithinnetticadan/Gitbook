# AD Audit

## [Group3r](https://github.com/Group3r/Group3r)

{% hint style="info" %}
Built to find vulnerabilities in Active Directory associated Group Policy.
{% endhint %}

### Basic Usage

* `group3r.exe -f <filepath-name.log>`&#x20;

## [PingCastle](https://www.pingcastle.com/documentation/)

{% hint style="info" %}
Powerful tool that evaluates the security posture of an AD environment and provides us the results in several different maps and graphs.
{% endhint %}

### Running PingCastle

* `PingCastle.exe`
* Default option is the `healthcheck` run, which will establish a baseline overview of the domain, and provide us with pertinent information dealing with misconfigurations and vulnerabilities

## [ADRecon](https://github.com/adrecon/ADRecon)

### Running ADRecon

* `.\ADRecon.ps1`
