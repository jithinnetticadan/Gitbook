# Memory Analysis

Obtain DB connection strings, internal server connections, protocol connection\
In scenarios where the string is encrypted, the value can be found decrypted and stored in the memory.

#### Tools:

* **WinHex** - Disk editor and universal hex editor\
  [https://www.x-ways.net/winhex/](https://www.x-ways.net/winhex/)
* **SystemInformer/ProcessHacker**\
  [https://systeminformer.sourceforge.io/downloads](https://systeminformer.sourceforge.io/downloads) or [https://github.com/winsiderss/systeminformer/](https://github.com/winsiderss/systeminformer/)
* **ProcessExplorer -** [https://learn.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite](https://learn.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite)
