# Dynamic Testing

## Tools and Labs

* [vphone-cli](https://github.com/Lakr233/vphone-cli) - virtual iPhone lab on Apple Silicon for runtime testing and debugging; [setup commands](../setup.md#virtual-jailbroken-iphone-on-apple-silicon).
* [MobSuite](https://mobsuite.app/#features) - device/Frida workspace; iOS support is in progress. The documented iOS device bridge uses libimobiledevice on macOS/Linux.
