# Reverse Engineering

#### Tools Used:

* **DotPeek** : .Net Decompiler, Covert exe -> cs files
* **dnspy** : .Net Runtime-Tracing, Modify Source Code & Recompile
* **ILSpy** & **Reflexil** - .Net Decompile & edit assembly code and save as new exe file (copy the dll file in reflexil to ilspy folder and launch) - view button -> reflexil (to view the assembly code and modify)
*  **ilasm** - Assembler  \
  **idasm** - Disassembler
* **jd-gui** - Java decompiler
* **Immunity Debugger**, **IDA Pro** - C/C++ decompiler
* **Decompiler Explorer**
